# Prediction of Multi-Vendor Trucking Performance Using Machine Learning

This repository contains the implementation of my undergraduate thesis entitled:

**Prediction of Multi-Vendor Trucking Performance in the Delivery Process at PT Leschaco Logistic Indonesia Using Machine Learning Algorithms with Dashboard-Based Visualization**

## Project Overview

The objective of this project is to predict trucking vendor performance using historical shipment data. Two machine learning algorithms are compared:

- Random Forest
- Naive Bayes

The prediction results are presented through an interactive dashboard to support monitoring and data-driven decision making.

## Features

- Data preprocessing
- Missing value handling
- Feature engineering
- SMOTE oversampling
- Random Forest model
- Naive Bayes model
- Model evaluation
- Interactive dashboard
- Vendor performance monitoring

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Technologies

- Python
- Pandas
- NumPy
- Scikit-Learn
- Imbalanced-Learn
- Plotly
- Streamlit
- Matplotlib
- Seaborn

## Dataset

The original dataset belongs to PT Leschaco Logistic Indonesia and is confidential.

Only the notebook and implementation are provided.
